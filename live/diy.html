Point AI at your database — free, in five minutes

Works with Claude, ChatGPT, or Gemini and the CRM you already have. This won't text anybody for you — but it will read your leads and hand you the follow-up, which is more than most databases got last month.

1

Get an API key from your CRM

In Follow Up Boss: Admin → API → Create API Key. Name it "AI test — delete me."

Not on Follow Up Boss? Search your CRM's settings for "API key" and swap the CRM name in the prompt below.

Read this before you paste anything

An API key is the keys to your house — it opens your entire database, and it never expires on its own. So: create a fresh key just for this exercise, delete it as soon as you're done (same page, trash icon), and never paste it while your screen is shared or recorded. Thirty seconds of housekeeping, and you can experiment all you want.

2

Open your AI and paste the key + this prompt

One message, key first, prompt after. Then watch it work.

Copy · paste · replace the red part 
My Follow Up Boss API key: [PASTE YOUR KEY HERE]

Pull the last 10 leads from my Follow Up Boss CRM. For each one give me:
1. One line on who they are and where we left off
2. A text message to re-engage them today
3. A short follow-up email
Reply in the language each lead used (English or Spanish), keep every
text under 300 characters, and flag anyone who looks ready for an
appointment.
3

Send the follow-ups. Delete the key.

The texts and emails it writes are yours — send the good ones today. Then go back to Admin → API and delete "AI test — delete me." That's the whole habit.
